# SEP-0142: Model Context Protocol (MCP) Transactional Saga Specification

- **Author:** Christophe Hochart
- **Status:** Draft / Active Reference Implementation
- **Type:** Standards Track / Protocol Extension
- **Created:** 2026-11-01
- **Reference Implementation:** https://github.com/hochart/mcp-saga

---

## 1. Abstract

The Model Context Protocol (MCP) standardizes how autonomous LLM agents discover, read, and mutate external tools and environments. However, current MCP tool executions operate strictly over isolated, atomic, non-transactional request-response RPCs. When an autonomous agent attempts a multi-turn mutation task, any failure at step N stranded in external services causes unrecoverable state corruption.

SEP-0142 specifies an opt-in, non-breaking protocol extension introducing Saga Mechanics, Pre-Image Reverse Compensation Synthesis, and LIFO WAL Rollback Primitives to MCP.

---

## 2. Motivation & Problem Statement

Autonomous agents frequently fail non-deterministically due to downstream schema constraints, context limits, or timeouts. Under standard MCP semantics, mutations executed prior to step N persist, corrupting baseline data.

SEP-0142 bridges this gap with zero-trust proxy interceptor boundaries: before a mutating tool call is forwarded downstream, a deterministic pre-image is captured and an idempotency-tested compensating inverse action is stored inside an append-only Write-Ahead Log (WAL).

---

## 3. Protocol Extensions

Extended JSON-RPC Methods:
- `saga/begin`: Initializes a transactional session boundary.
- `tools/call` with `_saga`: Augments tool calls with checkpoint metadata.
- `saga/commit`: Verifies the audit chain and seals the journal.
- `saga/abort`: Triggers immediate automated LIFO rollback compensations.

---

## 4. Benchmark & Performance Validation

Benchmarked on Apple Silicon (Darwin arm64):
- Integrity on Downstream Crash: 100% restored baseline.
- Rollback Execution Latency: 0.01 seconds.

---

## 5. Backward Compatibility

Existing MCP servers run completely unmodified downstream.
